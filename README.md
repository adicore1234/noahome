# המקום של נעה 🎨 — דף נחיתה + ממשק ניהול

אתר חד-עמודי לסטודיו "המקום של נעה" (גבעתיים) **עם ממשק אדמין מלא לעריכת כל התוכן** — טקסטים, תמונות, צבעים, כרטיסים, קישורים — עם תצוגה חיה בזמן עריכה.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | האתר הציבורי — קובץ אחד, כל התוכן מגיע מ-`content.json` |
| `content.json` | כל התוכן: טקסטים, תמונות, צבעים, קישורים (מקור האמת) |
| `admin/index.html` | ממשך העריכה — נפתח ב-`/admin/` |
| `vercel.json` | הגדרות דיפלוי ל-Vercel |
| `assets/` | תמונות האתר (כולן מקוריות מהאינסטגרם/פייסבוק של העסק) |

## ממשק האדמין (`/admin/`)
**התחברות:** משתמש `noahome` · סיסמה `12345678`
(הגנת נוחות בצד הלקוח — לא אבטחת שרת. כשמחוברים לשרת אמיתי כדאי להוסיף אימות גם שם.)

מה אפשר לערוך — הכל: SEO וכותרת · **10 פלטות צבע מוכנות** (הנוכחית מסומנת ⭐ "הפלטה המקורית" — לחיצה אחת מחליפה את כל צבעי האתר, ואפשר לכוונן צבעים בודדים מתחת) · לוגו ותפריט · כל טקסט בפתיח · כרטיסי פעילויות (הוספה/מחיקה/סידור + צבע לכרטיס) · סטריפ "קורה עכשיו" (כולל הסתרה) · אודות נועה · פוסטר המערכת · **גלריה — קרוסלה מקצועית נעה** (מעבר אוטומטי, חצים, נקודות, גרירה/סוואייפ וחצי מקלדת) · יצירת קשר · פוטר.
**תמונות**: העלאה מהמחשב/טלפון (כיווץ אוטומטי ל-1280px) או כתובת URL.
**תצוגה חיה**: האתר מוצג בתוך האדמין (מחשב/נייד) ומתעדכן בכל הקשה.

## שמירה ופרסום
- **מצב מקומי (ברירת מחדל):** שמירה אוטומטית ב-localStorage של הדפדפן — מושלם לעבודה מקומית ולתצוגה ללקוח.
- **פרסום לכולם:** כפתור **⬇️ ייצוא** מוריד `content.json` — מחליפים את הקובץ ב-repo ומעלים (Vercel מפרסם).
- **⬆️ ייבוא** — טעינת content.json חזרה · **↺ איפוס** — חזרה לתוכן המקורי.

## 🍃 MongoDB — מחובר ועובד!
התוכן מאוחסן ב-MongoDB Atlas (cluster0) דרך `api/content.js` (Vercel serverless):
- **GET /api/content** → מחזיר את התוכן מהמסד (בהרצה ראשונה זורע אוטומטית מ-content.json). אם המסד לא זמין — נופל בחזרה לקובץ, והאתר לעולם לא נשבר.
- **POST /api/content** → שומר. דורש כותרות `x-admin-user` / `x-admin-pass` (האדמין שולח אוטומטית את פרטי ההתחברות). בלי → 401.
- האדמין מחובר אוטומטית (כיתוב "מחובר לשרת" בפינה), העריכות נשמרות לשרת ("נשמר בשרת ✓") ומופיעות לכל הגולשים מכל מכשיר.

### משתני הסביבה (`.env` — מקומי; ב-Vercel: Settings ← Environment Variables)
| משתנה | תפקיד |
|---|---|
| `MONGODB_URI` | מחרוזת החיבור של Atlas (הסוד שלך) |
| `MONGODB_PASSWORD` | אופציונלי — אם ה-URI מכיל `<password>` |
| `MONGO_DB` | שם המסד (ברירת מחדל: `noa_site`) |
| `ADMIN_USER` / `ADMIN_PASS` | אימות השמירה (ברירת מחדל: noahome / 12345678) |

⚠️ **`.env` לעולם לא עולה ל-git** (.gitignore מכסה: `.env`, `*.env`). ב-Vercel מגדירים את המשתנים בדאשבורד.

### הרצה מקומית (שרת Node עם API + קבצים)
```bash
cd noa-studio
node local-server.js
# האתר: http://localhost:8123 · האדמין: http://localhost:8123/admin/
```
(דורש `npm install` פעם אחת — כבר בוצע.)

### דיפלוי ל-Vercel
אותו פוש כרגיל — Vercel מזהה לבד את `api/content.js` כפונקציה ומריץ `npm install` לפי package.json. לאחר ה-import:
Settings ← Environment Variables ← להוסיף את `MONGODB_URI`, `MONGO_DB`, `ADMIN_USER`, `ADMIN_PASS` ← Redeploy. זהו — האתר, האדמין והמסד חיים.

> בשדה הערך של Vercel מדביקים רק את הכתובת שמתחילה ב־`mongodb+srv://` — ללא `MONGODB_URI=` וללא מרכאות. הקוד מנרמל כעת גם ערכים כאלה, אבל זהו הפורמט המומלץ.
